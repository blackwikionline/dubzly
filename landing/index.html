Per-character AI voices for subtitled anime.

dubzly is a Chrome extension that mutes the original audio and overlays an AI voice for every line of dialogue — a different voice per character, in sync with the video.

How it works

1

Captures the subtitle track

dubzly intercepts the subtitle file the player already fetches — every cue, every speaker name, with proper start/end timing. Works for both .vtt and .ass shows.

2

Voices each character

Each speaker name maps to a distinct voice. ElevenLabs for production quality, or the browser's built-in TTS for free. Pick voices per character, save and share presets.

3

Plays in sync

The original audio is muted; the dub plays through your speakers, scheduled against the video's playhead. Pause, seek, and rate changes all behave correctly.

Community voice presets

Voice-matching every character in a show takes effort. Once you've done it, export the preset as JSON and share with friends — or upload to the community library, keyed by the show's URL slug. Other viewers see your preset suggested automatically.

Install

dubzly is in early access. Until it's on the Chrome Web Store, you can load it unpacked from the GitHub repo.

  1. Clone or download the repo: git clone https://github.com/blackwikionline/dubzly
  2. Build the extension: cd dubzly/extension && npm install && npm run build
  3. Chrome → chrome://extensions → enable Developer mode → Load unpacked → pick the extension/dist folder
  4. Open the popup, paste your ElevenLabs API key (or skip and use the browser's built-in TTS), open any Crunchyroll episode, press play.
