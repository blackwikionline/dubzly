How it works

1

Catches the subs

dubzly intercepts the subtitle track the player already loads — every cue, every speaker name, with proper timing. Works on both .vtt and .ass shows.

2

Voices each character

Aki gets one voice, Joe gets another. Pick voices per character from the popup, save the mapping, share it. ElevenLabs for quality or your browser's TTS for free.

3

Plays in sync

Original audio muted, dub plays through your speakers, scheduled against the video's playhead. Pause, seek, rate changes — all behave correctly.

community presets

Don't voice-match every show alone.

Once you've picked voices for a show, export the preset as JSON and share it. Or upload it to the community library — keyed by the show's URL slug, so other dubzly viewers see it suggested automatically when they open the same show.

Install

dubzly is in early access. Until it's on the Chrome Web Store, you can load it unpacked from the GitHub repo.

  1. clone git clone https://github.com/blackwikionline/dubzly
  2. build cd dubzly/extension && npm install && npm run build
  3. load Chrome → chrome://extensions → enable Developer mode → Load unpacked → pick extension/dist
  4. watch Open any Crunchyroll episode, paste your ElevenLabs key in the popup (or skip it for free browser TTS), press play.
